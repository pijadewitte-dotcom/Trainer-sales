# Trainer Sales

Offline HTML/PWA-app voor showroomverkoop van jacuzzi's, infraroodcabines en sauna's.

## Gebruik

Open `index.html` in een browser. Voor de volledige PWA/offline-installatie start je een kleine lokale webserver en open je de map in de browser.

## Wat zit erin

- Live klantmodus
- Diagnosegenerator
- Productframes
- Doorzoekbare bezwarenbibliotheek
- Belgische closingflow
- Follow-up tekst met kopieerknop
- 3-seconden stilte trainer
- Random oefenmodus
- Gespreksscore
- Reviews met localStorage
- CSV-export voor reviews
- PWA-manifest en service worker

## Belangrijk voor Codex

Hou de app praktisch. Dit moet bruikbaar zijn terwijl een klant binnenkomt. Geen overbodige uitleg, geen zware frameworks tenzij expliciet gevraagd.
